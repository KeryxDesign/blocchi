# Blocchi

Libreria di tutti i blocchi a disposizione per le pagine di vendita Keryx, per sezione dello scheletro (S0-S13). Fonti: Kx (nostri), HyperUI (MIT, anteprima), AstroWind (MIT, elenco). Non è il sito.

- indice alla radice, `/<id>/` un blocco da solo.
- Componenti in `src/components/vendita/` (copia da `KeryxDesign/keryx-design`: se cambiano lì, vanno riallineati qui). Elenco in `src/data/blocchi-vendita.ts`.
- `npm install && npm run dev`.
