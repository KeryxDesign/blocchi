# Blocchi

Catalogo interno dei blocchi di vendita Keryx (scheletro #204, S1-S12): ogni blocco in anteprima telefono 390 e computer 1440, con testi di esempio. Non è il sito.

- indice alla radice, `/<id>/` un blocco da solo.
- Componenti in `src/components/vendita/` (copia da `KeryxDesign/keryx-design`: se cambiano lì, vanno riallineati qui). Elenco in `src/data/blocchi-vendita.ts`.
- `npm install && npm run dev`.
